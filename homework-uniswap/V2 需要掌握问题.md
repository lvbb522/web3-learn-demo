# 1.什么是 AMM？它和订单簿模式有什么区别？

AMM 即 **Automated Market Maker**（自动做市商），它是一种**不依赖买卖双方挂单撮合**，而是通过数学公式和资金池来自动定价、自动完成交易的机制。

订单簿模式（Order Book）是传统交易所（如币安、纽交所）使用的模式。它的核心是：

- 买家挂**买单**，卖家挂**卖单**。
- 交易所把买单和卖单按价格排序，形成“买一、卖一”等深度。
- 当买单价格 ≥ 卖单价格时，**撮合成交**。
- 价格由**买卖双方的供需**决定，有人愿意买、有人愿意卖，才有价格。

### AMM 和订单簿的核心区别

|维度|AMM（如 Uniswap）|订单簿（如币安）|
|---|---|---|
|**定价方式**|数学公式（如 `x * y = k`）自动定价|买卖双方挂单，供需决定价格|
|**交易对手**|交易对象是**资金池**|交易对象是**另一个用户**|
|**流动性来源**|流动性提供者（LP）存入资金池|做市商或普通用户挂单|
|**撮合方式**|没有撮合，直接与池子兑换|交易所撮合买卖单|
|**价格滑点**|大额交易会沿曲线滑动，滑点较大|大额交易可分批挂单，滑点相对可控|
|**托管方式**|非托管，资产在用户钱包|托管，资产在交易所钱包|

# 2.AMM 的核心算法是什么？

不同 AMM 用不同公式，来适配不同资产类型，对于Uniswap V2而言，它的核心算法叫做 **xyk 恒定乘积自动做市商公式**（Constant Product Market Maker，CPMM），其公式为：**x×y=k**

- xx：池中代币 A 的数量
- yy：池中代币 B 的数量
- kk：常数（在无手续费、无外部注入/移除流动性时保持不变）

当你想要用Δx 数量的 A 换取 Δy 数量的 B时

- 交易前：x⋅y=k
- 交易后：(x+Δx)(y−Δy)=k
- 转换公式可得：Δy = (y⋅Δx​​) / (x+Δx)
- 算上手续费的话：Δy=(y⋅Δx(1−f)​) / (x+Δx(1−f)) ，其中手续费f通常等于0.003

# 3.什么是滑点？用户交易时如何避免滑点过高？

当你想要用A货币换取B货币，在交易执行之前，B货币的价格为：P1 = y​ / x
但是实际的成交价格：P2 = Δy / Δx = y / (x+Δx)
由于Δx>0，所以P2 < P1
P2 和 P1 之间的差值，就是滑点。

**避免滑点过高的方法有**

- 将一笔过大的交易拆分为多次小额交易，但要注意多次交易会增加整体的gas费用，注意两者之间的平衡
- 选择流动性更好，资金池更深的交易池
- 可以设置合理的滑点容忍度，但要注意如果容忍度过低的话可能会造成交易失败

# 5. LP 的作用是什么？

LP 即 **流动性提供者**Liquidity Provider 。LP 把自己的资产存入池子，让别人能交易，自己赚手续费，同时承担价格波动风险。在 xyk 模型里，LP 是整个 AMM 能运转起来的基础。

例如在一个已存在的ETH/USDT 池子中，你也可以按照当前相同比例的存入ETH/USDT成为LP，与此同时，你也能获得同等比例的LP TOKEN。你提供的ETH/USDT可以增加池子的流动性维持运转，你也可以获取交易手续费的分成，你可以随时使用自己的LP TOKEN赎回自己的ETH/USDT。

但要注意的是，成为LP获取手续费分成的同时，也会承担市场价格波动的风险，即**无常损失**。

# 6. 什么是无常损失？如何计算？

无常损失（Impermanent Loss，简称 IL）是 LP 最核心的风险来源。简单来说就是
**无常损失 = 你把资产放进 AMM 池子后，相比“单纯持有这些资产”，少赚的那部分。**

## 为什么会有无常损失

核心原因是**AMM 池子会自动卖涨买跌。** 当 ETH 涨价时套利者会从池子里买走便宜的 ETH，池子里 ETH 变少，USDT 变多-，你手里原本的 ETH 被卖掉了。当 ETH 跌价时套利者会往池子里卖 ETH，池子里 ETH 变多，USDT 变少，你被动接盘了 ETH。**池子总是让你在涨的时候少赚，在跌的时候多亏**， 这就是无常损失的来源。
